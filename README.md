# Komentář k zákonu č. 231/2025 Sb., o řízení a kontrole veřejných financí

Odborný komentář k **zákonu č. 231/2025 Sb., o řízení a kontrole veřejných financí (RKVF)** — nástupci zákona o finanční kontrole (č. 320/2001 Sb.): řídicí a kontrolní systém správců veřejných rozpočtů, schvalovací postupy a role příkazce operace, správce rozpočtu a hlavního účetního, nezávislý interní audit a harmonizační role Ministerstva financí. Nový zákon — judikatura k němu dosud neexistuje; navazuje na sesterský komentář Komentar-ZFK-320-2001.

Konsolidované znění: dokument e-Sbírky `SB-2025-00231_2025-07-10`.
